| 소스 | 기준 시점 | 무엇에 쓰나 |
|---|---|---|

| **브랜드별 월별 대조표** (아포맨/루테카/식물나라) | **진행월** | 진행 수량 · 마크업 전/후 단가 · 확정 여부 |

### 확인된 귀속 규칙 (아이디얼포맨으로 완전 검증됨)

```
세금계산서 발행월 = 진행월 + 1개월,  지급대행은 별도 가산
```

| 검증 | 결과 |
|---|---|
| 발행 2월 71,375,000 = 진행 1월 31,250,000 + 진행 2월 40,125,000 | ✅ 정확히 일치 |
| 발행 4월 108,000,000 = 진행 3월 103,000,000 + 지급대행(트루컴) 5,000,000 | ✅ 정확히 일치 |
| 발행 5·6·7월 = 진행 4·5·6월 (74,125,000 / 32,125,000 / 16,125,000) | ✅ 정확히 일치 |
| 아포맨 총액 = 진행 1~6월 296,750,000 + 지급대행 5,000,000 + 8월 발행 32,000,000 | ✅ **333,750,000 정확히 일치** |

대조표의 `식물나라 6월 → "7월귀속"`, `7월 → "8월 귀속"` 주석도 같은 규칙이다.
